## 💡 为什么需要这套营销 Skills 专区？

大多数通用大模型在处理营销和策略任务时，常常陷入三大通病：
1. **黑话堆砌与万字废话**：动辄“心智占领、赋能闭环、全域共振”，洋洋洒洒数千字，通篇没有一句可在真实商业环境中执行的动作。
2. **缺乏商业张力与因果逻辑**：做竞品分析只会列浮于表面的 SWOT，做用户画像只会写“25-35 岁一二线都市中产”，找不到行业惯性与消费者深层矛盾之间的撕裂点。
3. **缺少甲乙方实战博弈经验**：写 Brief 容易变成填鸭式卖点传声筒；给博主提修改意见要么生硬死板导致博主摆烂，要么太软弱无法满足品牌商业诉求；写活动结案只会堆砌无意义的曝光数字。

**`wensen-marketing-skills` 的解法：立足本质、去班味、任务直驱。**  
通过 21 个经过实战检验的 Agent Skills，将 4A 策略总监、创意制片人、合规法务与资深媒介的推演思考路径代码化，让你的 AI 真正成为懂商业、说人话、可交付的同行级策略搭档。

## 🚀 安装与多 Agent 极速部署指南 (Deployment)

本技能库采用标准的现代 Agent Skills 规范（`SKILL.md` + YAML Frontmatter），全面兼容市面主流 Coding Agent 与 AI 辅助工具。

### 方式 1：一键挂载至本机主流 Agent 环境（推荐，秒级生效）

先将本仓库克隆至本地任意目录：
```bash
git clone https://github.com/wensenlab/wensen-marketing-skills.git ~/wensen-marketing-skills
```

根据你日常使用的主力工具，执行对应的一行命令即可完成全量 21 个技能的软链接挂载：

* **Claude Code**：
  ```bash
  mkdir -p ~/.claude/skills && for skill in ~/wensen-marketing-skills/skills/*; do [ -d "$skill" ] && ln -sfn "$skill" ~/.claude/skills/$(basename "$skill"); done
  ```
* **Codex**：
  ```bash
  mkdir -p ~/.codex/skills && for skill in ~/wensen-marketing-skills/skills/*; do [ -d "$skill" ] && ln -sfn "$skill" ~/.codex/skills/$(basename "$skill"); done
  ```
* **Google Antigravity (AGY)**：
  ```bash
  mkdir -p ~/.gemini/antigravity/skills && for skill in ~/wensen-marketing-skills/skills/*; do [ -d "$skill" ] && ln -sfn "$skill" ~/.gemini/antigravity/skills/$(basename "$skill"); done
  ```
* **Cursor / 项目级通用挂载**：
  ```bash
  # 全局通用挂载
  mkdir -p ~/.agents/skills && for skill in ~/wensen-marketing-skills/skills/*; do [ -d "$skill" ] && ln -sfn "$skill" ~/.agents/skills/$(basename "$skill"); done

  # 或在当前具体工程项目根目录下挂载
  mkdir -p .cursor/skills && for skill in ~/wensen-marketing-skills/skills/*; do [ -d "$skill" ] && ln -sfn "$skill" .cursor/skills/$(basename "$skill"); done
  ```

### 方式 2：通过 Skills Manager 统一纳管（`skills-manager-cli`）

如果你在本地使用开源的 **Skills Manager**（`skills-manager-cli`）统一管理 Agent 技能，可直接通过 CLI 一键安装与分发：

```bash
# 从 GitHub 仓库一键安装至本地中央技能库
skills-manager-cli skills install https://github.com/wensenlab/wensen-marketing-skills.git --subpath skills/brand-strategy-analyst

# 部署至指定 Agent 环境
skills-manager-cli skills deploy --agent claude_code brand-strategy-analyst
skills-manager-cli skills deploy --agent antigravity brand-strategy-analyst
```

### 方式 3：按需单个复制使用

如果你只需要其中的某一个技能（例如只想要《广告法极限词排雷》或《反向 Brief》）：
直接把对应的技能文件夹（如 `skills/ad-law-compliance-guard`）复制到你当前项目的 `.agents/skills/` 目录下即可，无任何外部构建依赖。

## 🌟 核心设计哲学与规范约束

1. **商业破局始于市场张力 (Tension First)**：拒绝流于表面的 SWOT 罗列。真正的战略破局点，永远藏在“行业默认的共识惯性”与“消费者深层未被满足的矛盾”之间的拉扯中。
2. **直切人群心智切片 (Deep Persona)**：彻底终结“25-35 岁一二线都市中产”这类无效标签，穿透至微观生活场景、社交防御机制、心理阻力与真实买单账户。
3. **语言去班味，客观求真 (Human-Writing)**：严密过滤“赋能、闭环、抓手、心智占领”等空洞大厂套话，用通俗精准的商业人话讲透因果逻辑。
4. **平等松弛，拒绝爹味 (No Preaching)**：绝不以居高临下的导师口吻教读者做事，杜绝命令式训导，以第一人称实战与同行交流的平视视角输出建议。
5. **标点与排版对齐**：中文语境下严格对齐全角中文标点，保持 1～2 句微段落呼吸感。
