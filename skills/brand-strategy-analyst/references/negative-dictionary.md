# 品牌策略黑话过滤词典与正向表达替换表 (Negative Dictionary)

> **方法论底色**：真正的品牌战略专家用通俗、严密、有锋芒的商业人话讲透事物本质。堆砌大厂套话和公关假大空词汇，往往是为了掩盖思考的懒惰和洞察的苍白。本词典作为品牌策略推演的严苛过滤红线。

---

## 1. 大厂空泛套话 vs 商业通俗人话

| 严禁出现的黑话 | 产生的问题 | 推荐的正向商业人话替换 |
| :--- | :--- | :--- |
| **赋能** | 抽象空洞，缺乏主体责任感 | **提供支持 / 降低门槛 / 帮助实现 / 赋予能力** |
| **闭环** | 机械大厂做派，言之无物 | **完成全流程 / 跑通商业链路 / 形成可自运转的良性循环** |
| **抓手** | 粗俗机械，缺乏策略美感 | **核心切入点 / 关键动作 / 战略杠杆 / 突破口** |
| **心智占领** | 把消费者当成被征服的猎物 | **赢得长期偏爱 / 建立首选记忆 / 成为心照不宣的选择** |
| **底层逻辑** | 伪深刻、高频滥用的口头禅 | **本质原因 / 因果链条 / 商业运作机理** |
| **打法** | 充满暴力好战的粗鄙意象 | **策略路径 / 实施步骤 / 经营做法** |
| **矩阵式推进** | 虚张声势的排比术语 | **多渠道协同 / 分模块有序落实** |
| **拉齐基本盘** | 内部会议腔调，不解决实际问题 | **确立事实共识 / 锁定业务基准线** |
| **痛点切片** | 生造术语，故作专业 | **具体生活场景中的阻力 / 关键使用摩擦点** |
| **深度共鸣** | 悬浮且不提供因果证明 | **击中其未被言说的委屈 / 获得打心底的文化认同** |
| **思考脚手架** | 浮夸生造概念 | **推演框架 / 分析步骤** |
| **心智流转** | 故弄玄虚的心理学术语 | **决策心理演进 / 信任逐渐建立的过程** |

## 2. 夸张营销与煽情浮夸词清单

严禁在策略推演中为了博取眼球或渲染效果而使用以下廉价、低质的营销词汇：

| 严禁词汇 | 严禁理由 | 替代方案 |
| :--- | :--- | :--- |
| **神级、天花板、最强、第一** | 违反商业求真原则，缺乏事实支撑，涉嫌虚假宣传 | 用**具体行业排名、第三方客观评测数据、可量化实测指标**代替。 |
| **颠覆认知、降维打击、暴力提升** | 情绪绑架与粗暴夸张，缺乏职业咨询师的严谨底色 | 用**重构品类规则、改变成本结构、大幅缩减耗时**等客观商业描述。 |
| **必看、重磅、绝绝子、绝了** | 低幼化社媒噪音，丧失专业提案格调 | 直接开门见山陈述**核心论据与战略结论**。 |

## 3. 居高临下与“爹味”命令腔过滤

在策略提案与叙事推导中，坚决杜绝把受众或读者预设为“愚钝无知、需要被导师教训”的傲慢姿态：

- ❌ **严禁用语**：`“你要……”`、`“你应该……”`、`“我教你……”`、`“别再……了，去……吧”`、`“怎么还在……”`、`“听我一句劝……”`
- ✅ **倡导表达**：
  - 以平等尊重的平视视角展开探讨；
  - 正面陈述事实、商业规律与自身实战经验；
  - 启发式推演：“从数据与市场反馈来看，另一个更值得投入的方向是……”；
  - 把目标受众当成聪明的同行与审慎的决策者。

## 4. 二元对立句式弹性边界 (Antithesis Guidelines)

- **在品牌主张与传播叙事中（严格杜绝翻案说教）**：
  - 严禁通篇使用 `“不是……而是……”`、`“不再……而是……”`、`“并非……仅仅是……”` 这类居高临下的翻案句式来否定传统或教训读者。
  - **正确做法**：直接正面描绘品牌所倡导的理想生活方式、真实质感与鲜活细节。
- **在商业竞品差异化与客观界定中（允许自然对比）**：
  - 当用于界定产品参数边界、区分商业商业模式（如纯直销 vs 经销代理）、排查技术指标时，允许采用清晰客观的中性对比表格或陈述。
