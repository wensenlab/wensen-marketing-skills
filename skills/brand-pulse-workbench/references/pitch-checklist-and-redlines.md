# 品牌比稿看板自检清单与负面词红线 (Checklist & Redlines)

在完成任何比稿看板（BrandPulse Workbench）的策略推演与 HTML 编译前，必须严格对照本清单逐项自检。

---

## 1. 思想与策略自检 (Strategy Depth)

- [ ] **洞察是否具备真实张力？** 
  - 是否挖掘出了人群“渴望与现实的矛盾冲突”，而不是单纯罗列“喜欢高品质、追求性价比”等正确废话？
- [ ] **四象限坐标轴是否具备战略锐度？**
  - 是否避免了“低价 ⟷ 高价”、“低质 ⟷ 高质”等无意义平庸轴？
  - 是否明确标明了竞品聚集的红海区域，以及本品所占据的全新蓝海战略楔子？
- [ ] **三大 Core Idea 是否有本质流派差异？**
  - 是否真正覆盖了“社会情绪共振流”、“产品力戏剧化流”、“圈层文化反叛流”三大不同哲学方向，绝非换词套皮？
- [ ] **整合营销战役排期是否具体可落地？**
  - 预热、爆发、发酵三阶段动作是否具体可行，有明确的触点与内容载体，杜绝抽象名词堆砌？

---

## 2. 语言去班味与负面词红线 (Tone & Redlines)

严格遵守 WenSenLab 全局负面约束清单：

| 严禁出现的假大空与黑话 | 推荐的人性化表达 |
| :--- | :--- |
| **赋能、闭环、抓手、打法、心智占领** | 具体动作说明（如：提供支撑、配合完成、建立认知） |
| **降维打击、天花板、神级、颠覆认知** | 用具体的对比数据或客观事实说话 |
| **你要……、你应该……、别再……了去……吧** | 采用第一人称实战、同行平视探讨视角 |
| **底层逻辑、思考脚手架、痛点切片** | 换成直白的因果关联与真实生活场景 |

---

## 3. Generative UI 与前端交互自检 (Code & UI Quality)

- [ ] **单文件自包含**：整个看板必须整合在单一 `.html` 文件中，所有 CSS 与 JS 内嵌，通过 CDN 引入 Tailwind，无需任何本地构建或外部依赖。
- [ ] **离线双击可用**：双击本地 `.html` 文件在默认浏览器（Safari / Chrome / Edge）打开即可完美展现，无报错或资源跨域裂解。
- [ ] **自适应品牌美学**：
  - 调色盘与字体是否与目标品牌调性精准契合（科技/人文/潮流/奢华/新能源）？
  - 是否杜绝了刺眼的生硬纯黑纯白撞色，具有微磨砂或自然大地纸质质感？
- [ ] **核心交互完整闭环**：
  - **选项卡切换**：点击 3 组 Core Idea 按钮时，内容平滑切换，选中态高亮明确；
  - **动态四象限**：SVG 坐标图渲染正常，鼠标悬停品牌散点时显示精致 Tooltip 浮层；
  - **一键复制**：点击“复制策略摘要”时，剪贴板成功写入纯净 Markdown 并触发 Toast 提示；
  - **打印与 PDF 导出优化**：按 `Cmd + P` / `Ctrl + P` 预览打印时，操作工具栏自动隐藏，三大概念自动平铺展开，无截断与排版错乱。

- [ ] 顶部导航明确标注提案品牌与副标；
