# 社媒金句与核心观点内容提炼指南 (Content Extraction Guide)

本指南规范了在调用 `social-card-maker` 时，如何将用户的原始文本（长篇文章、随笔手记、访谈实录或零碎观点）转化为具有强穿透力与知性美感的结构化卡片文案。

---

## 1. 核心提炼四大支柱 (Four Core Pillars)

```
┌────────────────────────────────────────────────────────────────────────┐
│ 1. 抓手标题 (Hook)        ➔ 8～14 字，好奇反差，平视探讨，拒绝居高临下     │
│ 2. 核心金句 (Core Quote) ➔ 1～3 句（60～150 字），微段落呼吸感，正面直陈  │
│ 3. 补充洞察 (Sub-Takeaway)➔ 1 句精炼注脚或破局点，支撑金句落点           │
│ 4. 元数据与出处 (Meta)    ➔ 场景标签 + 日期 + 作者/出处 + 文森策版权钢印    │
└────────────────────────────────────────────────────────────────────────┘
```

---

## 2. 吸睛钩子标题提炼法则 (Hook Headline)

- **字数控制**：严格控制在 **8～14 个汉字**。
- **风格定调**：
  - ✅ **好奇反差向**：揭示直觉与真相的戏剧张力（如：`好策略通常让人觉得松弛`、`真正贵的不是工具而是试错`）；
  - ✅ **真实场景向**：直击特定场景下的体感（如：`比稿前夜的最后三道验算`、`别把技术流程当成了业务结果`）；
  - ❌ **严禁说教爹味**：绝对禁用“别再……了，去……吧”、“我教你如何……”等命令式训导句；
  - ❌ **严禁夸张恐吓**：禁止“颠覆认知”、“必看”、“暴力提效”等夸张营销词。

---

## 3. 核心金句提炼法则 (Core Quote)

- **篇幅规格**：总长度 **60～150 字**，拆分为 **1～3 个微段落**（每段 1～2 句），留足视觉呼吸空间。
- **正向陈述与事实细节**：
  - 直接陈述“它是什么、在什么场景下解决什么、有何体感”；
  - 杜绝在观点输出中频繁使用“不是……而是……”等居高临下的二元翻案句式；
  - 杜绝“赋能、闭环、心智占领、打法、底层逻辑”等大厂黑话与空泛套话。
- **示例对比**：
  - ❌ *大厂空话版*：“通过系统化赋能内容全链路闭环，重构商业底层逻辑，占领用户心智高地。”（毫无信息增量）
  - ✅ *知性活人版*：“好方案往往不在于堆砌了多少专业术语，而在于能否在两分钟内，把复杂的业务矛盾讲成普通人一听就懂的常识。把话说透，方案才真正开始生效。”

---

## 4. 补充洞察与注脚 (Sub-Takeaway)

- 控制在 **20～45 字**；
- 作用是承接上方金句，给出具象的行动启发或深层总结；
- 示例：`「当你停止向客户证明自己懂很多时，对话才真正对准了生意本身。」`

---

## 5. 元数据与出处规约 (Meta & Stamp)

1. **场景标签 (`#TAG`)**：
   - 提取 1～2 个核心主题标签，如 `#商业洞察`、`#策略手记`、`#品牌策划`、`#AI探索`、`#工作哲学`、`#创作者思考`。
2. **日期 (`DATE`)**：
   - 格式统一为 `YYYY.MM` 或 `YYYY.MM.DD`，如 `2026.10`。
3. **作者与出处 (`AUTHOR · SOURCE`)**：
   - 若用户提供了文章标题或出处，格式为：`文森策 · 《文章名/手记名》`；
   - 若未提供出处，默认为：`文森策 · 个人手记`（或用户指定的作者姓名）。
4. **版权钢印 (`WATERMARK`)**：
   - 统一使用：`WenSenLab_ ©文森策`。
